# Notes

Self-contained study notes for PPHA 41501, in Markdown with LaTeX math.

Each file is an **original write-up** synthesizing a lecture — page-by-page, in the
author's own words, drawing on the slides and textbook (Myerson, Osborne, MWG). They are
summaries, not reproductions of the source material.

## Naming

- `Lecture-N-Slug.md` — one file per lecture (e.g. `Lecture-1-Games-in-Strategic-Form.md`).
- Each file ends with a **Difficulty checklist** of concepts to review.

## Ground rules

- Write in your own words, and cite the source inline (slide page, textbook section) so
  others can verify.
- Do **not** paste the slides or textbook text verbatim, and do **not** commit the source
  PDFs — they are copyrighted and live outside this repo.
